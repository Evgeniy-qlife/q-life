# 🌌 Q-Life (Квантовая жизнь)

Open-source приложение, которое использует искусственный интеллект и квантовые алгоритмы (QAOA, Grover, VQE) для моделирования жизненных путей.

Мы переводим психологию и цели человека в математические векторы (Энергия, Капитал, Знания) и находим кратчайший путь к процветанию.

## 🚀 Демо
Откройте файл `index.html` в любом браузере, чтобы увидеть симуляцию.

## 🛠️ Стек
* Python, Flask, Qiskit
* OpenAI API
* HTML, JS, Chart.js
